# Videos

One folder per video: `NNN-short-name/` (e.g. `001-steal-an-egg-myths/`).

Each folder gets:
- `brief.md`: copied from `templates/video-brief.md`
- `script.md`: copied from `templates/script-template.md` (written after recording)
- `notes.md` (optional): footage notes, links, screenshots list
